## 🤔 What Is rebasis?

rebasis is a simple tool that helps you decide if upgrading your AI embeddings is worth the effort. Embeddings are how AI systems understand text and images. When you upgrade them, you usually have to rebuild everything. rebasis tells you if it's worth it, helps you switch without rebuilding, and guides you when you're ready to make the move safely.

Think of it like this: your AI system uses a "language" to understand data. rebasis checks if learning a new "language" is better, helps you translate without rewriting your books, and ensures you don't lose anything during the change.

## 📖 How to Use rebasis (Simple Examples)

### Check If an Upgrade Is Worth It

```
rebasis check --current old-model --new new-model --data your-data
```

This tells you a score from 0 to 100. If it's above 70, the upgrade is worth it. Below 50? Don't bother.

### Bridge Without Reindexing

```
rebasis bridge --from old-model --to new-model
```

This makes your system think it's using new embeddings while keeping your old data untouched. You can test everything first.

### Migrate Safely

```
rebasis migrate --from old-model --to new-model --backup yes
```

This moves your data step-by-step. If anything goes wrong, rebasis automatically restores your backup.
